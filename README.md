# 🧠 Memory Card Game

A simple and interactive memory card game built with **HTML**, **CSS**, and **JavaScript**. Test your memory skills by matching pairs of cards in the fewest moves possible.

## 🎮 Live Demo

Play the game here: [Memory Card Game](https://petrabayu.github.io/memory-card-game-js/)

## 🧩 Features

* **Interactive Gameplay**: Click on cards to flip and find matching pairs.
* **Smooth Animations**: Enjoy seamless flipping animations for an engaging user experience.
* **Score Tracking**: Keep track of your moves and aim for the best score.

## 🛠️ Technologies Used

* **HTML5**: Structuring the game layout.
* **CSS3**: Styling and animations.
* **JavaScript (ES6)**: Game logic and interactivity.

## 🚀 Getting Started

To run the game locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/petrabayu/memory-card-game-js.git
   ```
2. **Navigate to the project directory**:

   ```bash
   cd memory-card-game-js
   ```
3. **Open `index.html` in your preferred browser**.
